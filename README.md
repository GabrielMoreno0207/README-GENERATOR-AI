# README Generator AI

Gerador de README utilizando a API do OpenAI para criar READMEs de projetos automaticamente com base em informações fornecidas pelo usuário. O aplicativo permite a personalização do README com detalhes como nome do projeto, descrição, tecnologias, licença e mais.

## 🛠 Tecnologias Usadas

- **React**: Para construção da interface de usuário.
- **Tailwind CSS**: Framework de CSS para estilização.
- **OpenAI API**: Para gerar o conteúdo do README automaticamente.
- **Backend Service**: integração da API e configuração de modelo gpt4 .
- **Vite**: Ferramenta de build e bundling.

## 🚀 Como Rodar o Projeto Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrielMoreno0207/README-GENERATOR-AI.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd README-GENERATOR-AI
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Crie um arquivo `.env` com sua chave de API da OpenAI:
   ```
   VITE_OPENAI_API_KEY=your-api-key-here
   ```

5. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

6. Acesse o projeto no navegador:
   [http://localhost:3000](http://localhost:3000)

## ⚡ Funcionalidades

- **Gerar README automaticamente**: O usuário preenche um formulário com o nome do projeto, descrição, tecnologias e outros detalhes, e o aplicativo gera um arquivo `README.md` pronto para uso.
- **Visualizar o README gerado**: Mostra o conteúdo do README em tempo real.
- **Editar README**: O usuário pode editar o conteúdo gerado diretamente na interface.
- **Copiar para área de transferência**: O README gerado pode ser copiado para a área de transferência com um clique.

### 💡 Como o projeto foi desenvolvido:

Este projeto foi criado com a intenção de facilitar a geração de arquivos `README.md` de forma rápida e eficiente.
